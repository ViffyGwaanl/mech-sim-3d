# 交互层：信息卡 · 拾取 · 视角 · 剖切 · UI

对应参考实现：92_parts.js（DB）、95_ui.js（其余全部）。CSS 体系在 00_head.html。

## 1. 零件信息库 DB（92_parts.js）

```js
DB[partId] = {
  zh:'活塞', en:'Piston', sys:'crank',        // sys → 徽章颜色/系统归属
  mat:'共晶 Al-Si 合金锻造，顶部 ω 燃烧室，裙部石墨涂层',   // 材料与工艺
  fn:'承受燃气压力经活塞销连杆传给曲轴…',                    // 功能（1–3 句）
  ps:[['直径','Ø101.9 mm'],['压缩高','55 mm'],...],          // 关键参数 kv 表
  st: u => `第${u.cyl+1}缸 · ${运动方向} · 位移 ${...} mm · 缸压 ${...} bar`
}
```

要点：

- `st` 是**闭包**，读全局 KIN/ST 实时算，悬停期间每帧刷新——"当前运动状态"
  是这个功能的灵魂，写成静态文本就废了。渲染处 try/catch，单条坏档案不能
  炸掉整个系统。
- `u = mesh.userData`，含 cyl/vtype 等实例信息，同一 partId 多实例各说各话。
- 双语在条目内并存（zh/en 字段 + 参数表内嵌单位），不做全局 i18n 开关（单文件
  场景收益低）。
- 写完跑覆盖检查：`PICKABLE 里出现过的 partId 集合 − DB 键集合 = ∅`。
- 内容要做研究：真实材料牌号、真实工艺、真实公差量级。信息卡是本类交付的
  核心教学价值，宁可零件少一点，档案不能水。

## 2. 拾取与高亮（95_ui.js）

- Raycaster ~22Hz 节流（不是每帧）；命中链上任何 parent.visible=false 则跳过
  （systems 显隐后必须 rebuildPick()）。
- 高亮：命中网格换成"克隆材质 + emissive 青色"，按源材质 uuid 缓存克隆
  （HLCACHE Map），离开时还原引用。不要改原材质（多网格共享）。
- 信息卡定位：跟鼠标 + clamp 进视口；结构=名称头（双语+系统徽章）/材料/功能/
  参数 kv/实时状态高亮框。卡片 pointer-events:none 防抖动。
- 双击 = Box3 包围盒对焦（controls.fly 到 size×1.9 距离）。

## 3. 视角系统

```js
VIEWS = { free/side/top/front/section/...：{t,r,p,h, clip?, cp?} }
setView(key, snap)   // snap=true 立即到位（测试/拆解镜头）；否则 fly 过渡
```

- 预设可携带剖切状态（section 视角自动开剖切并设剖面位置）。
- **剖视相机必须站在被切掉的那一侧**看向保留侧（法线 −Z 切掉 z>c，则相机 z
  要大于 c），站错侧看到的是完好外壳、白拍一轮截图——实测代理踩过。
- 构图用截图逐张校：目标机器占画面 60–75%，关键子系统不被 UI 面板遮挡。
  大型外围件（散热器/管路）容易挡正视角——把镜头抬高转 3/4 角绕开。
- **方向反转三件套是必配项**（渲染面板三个 tog：反转左右 / 反转上下 /
  反转滚轮缩放，接 ST.invX / ST.invY / ST.invZoom）：旋转分支乘 ±1，滚轮写
  `Math.pow(0.94, (ST.invZoom?-1:1)*e.deltaY*0.012)`。**默认必须是标准语义**
  （拖右→物体右转的抓取感；向后滚→拉远缩小），反转开关是给习惯不同的人的
  逃生口，不是默认值的替代品——两者别混为一谈：手感可以给选择，**方向写反
  是 bug**（本技能真出过：滚轮反向复制传播到全部 5 台机器，见
  verification.md 3.5）。操作引导里提一句开关入口在哪。
  Orbit.down 里的 setPointerCapture 要包 try/catch（合成事件/自动化测试会抛异常）。

## 4. 剖切 / 半透明 / 爆炸

- 剖切：一个全局 `THREE.Plane` 挂在所有 outer 材质的 clippingPlanes；
  滑块只改 `plane.constant`。材质 DoubleSide 防剖面漏底。
- 半透明（ghost）：遍历 OUTER 材质数组 opacity=.24 + depthWrite=false；
  恢复时读 userData.base 存的原值。
- 爆炸图：建模时对壳体件登记 `expl(mesh, [dx,dy,dz])`（基准位置+方向向量），
  滑块 t∈[0,1] 线性插值。方向按"真实拆卸方向"给（缸盖向上、油底壳向下、
  端盖沿轴向）。
- 系统显隐：GROUPS 每系统一个开关 + 计数徽章；改完 rebuildPick()。

## 5. UI 面板体系（00_head.html 的 CSS）

深色玻璃拟态体系，可整套复用：CSS 变量色板（--bg/--panel/--acc/--mono）、
.panel 圆角玻璃卡、.row 滑块行（滑块进度用 --p 变量画双色轨）、.tog 自绘
复选、.btns 按钮组、kbd 快捷键角标。布局：左列控制栈（可滚动）、右列仪表栈、
左下图例、右下 HUD（FPS/三角面/drawcall）、底部中央拆解字幕卡、? 帮助浮层。

仪表用 2D canvas 画（转速表圆弧+红区+指针、720° 冲程相位盘、p–θ 示功图 +
四冲程色带 + 游标点），≈14Hz 刷新。数字用 tabular-nums 防跳动。

## 6. 操作引导

首屏一张玻璃浮层：键位表（k 标签样式）+ 一句话技术口径声明（建模依据、
相位精度）+「开始」按钮。? 按钮随时唤回。引导里的键位必须与实际监听一致
——加新键时两处同步。

## 7. 快捷键实现细节

`e.target.tagName==='INPUT'` 时直接 return（滑块聚焦时空格别触发暂停）。
键位表：Space/1–5/C/X/F/P/E/H/R/T/[/]，语义见 SKILL.md。
