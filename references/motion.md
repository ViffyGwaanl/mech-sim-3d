# 运动学 · 流动 · 物理 · 拆解动画

对应参考实现：90_kin.js（运动学+物理）、80_flow.js（粒子）、96_teardown.js（拆解）。

## 1. 运动学总纲

**单一主角度驱动一切**。选一个主自由度（曲轴角 θ、输入轴角、摆角……），
`ST.theta` 是它的唯一状态；每帧 `updateKinematics()` 用闭式方程从 θ **绝对重写**
每个运动件的 position/rotation。两条铁律：

1. 绝不 `+=`。增量旋转会漂移，且拖动角度滑块/单步/拆解模式全部依赖
   "同一个 θ 永远给出同一个位形"。
2. 位置要**整组重写**（`position.set(x,y,z)` 而非只改 `.y`），拆解动画的
   加性偏移才能在其后安全叠加（见第 5 节）。

### 曲柄滑块（活塞式机器通用）

```js
s(φ) = r·cosφ + √(L² − r²sin²φ)        // 活塞销距曲轴中心
v(φ) = −ω·r·(sinφ + r·sinφcosφ/√(L²−r²sin²φ))
```

连杆姿态：从曲柄销世界点指向活塞销世界点的单位向量 →
`Quaternion.setFromUnitVectors(+Y, dir)`，连杆体/盖/瓦/螺栓全套同一四元数。
连杆上的偏置点（螺栓）：局部偏移向量 `applyQuaternion(q)` 后加曲柄销位置。

### 凸轮—从动件链

升程函数与凸轮几何共享相位常数（geometry.md 第 2 节）：

```js
liftOf(psi) : |Δ| = 环形差(psi/2, peak/2)   // 凸轮半速！角度全部除以 2
              lift = maxLift · camProfile(|Δ|/half)
挺柱.y += lift; 推杆.y += lift
摇臂.rotation.x = −asin(lift·rockerRatio / 摇臂气门端臂长)
气门.y −= lift·rockerRatio; 弹簧.scale.y = (自由长−升程)/自由长
```

四冲程机器凸轮轴 = 曲轴半速：`cam.rotation.x = −θ/2`（转向按齿轮系定）。

### 齿轮啮合相位

外啮合直齿轮 A 驱动 B，β = 连心线方位角（atan2），zA/zB 齿数：

```js
φB = β + π − π/zB + (zA/zB)·(β − φA)
```

含义：B 反转 zA/zB 倍，且在连心线处齿-槽对齐（π/zB 错半齿）。多级齿轮系
逐级套用。装配时目测一次齿是否咬合，再用 verification 的传动比断言锁死。

### 旋转链审计（交付前必做）

列出所有"应该旋转的东西"（齿圈、螺栓圈、皮带轮、叶轮……），逐个确认它挂在
旋转组内或被 updateKinematics 驱动。参考实现曾漏掉飞轮齿圈——飞轮转、齿圈静止，
非常显眼的穿帮。

### 浮动总成（悬挂/浮筏子系统）

洗衣机、压缩机、发动机悬置等一类机器的核心是**整个子总成浮在弹性悬挂上**：
建一个运动父组（如 SUSP），把外筒+内筒+电机+配重整体挂进去，振动位移只写
SUSP.position（叠加在各自局部运动学之上）。摆幅用单自由度受迫振动幅频公式：

```
A(ω) = (m·r/M) · η² / √[(1−η²)² + (2ζη)²]，η = ω/ωₙ
```

升速穿越临界转速时出现共振峰、过临界后自定心衰减——这既是真实物理也是绝佳
教学点（配一块幅频曲线画布 + 实时工作点）。跨接件（弹簧/减震器一端在静止
箱体、一端在运动组）按 kinematic 件处理：每帧由两端世界坐标重写位姿与长度，
拆解表里也要打 kin 标。实测代理在滚筒洗衣机上验证过整套写法。

## 2. 简化物理（驱动仪表与流量）

一阶滞后是主力：`X = lerp(X, target(rpm,load), k·dt)`。水温、油压、增压压力、
排温各配一个 target 函数 + 快慢不同的 k，仪表就"活"了且永不突跳。

需要示功图/缸压时上逐度积分（参考实现 buildCycle）：

```
封闭段：dp = (γ−1)·Q·dx/V − γ·p·dV/V     // 第一定律，Wiebe 放热 dx
换气段：与排气背压/进气压力做幂插值衔接
```

预计算成 721 元素查表数组，每 0.35s 随工况重算一次，运行时纯插值。
量级校核：柴油机全负荷 pmax 140–180 bar、倒拖 ≈ 压缩比^1.35 × 进气压。

## 3. 流动粒子（80_flow.js）

```
车道 = CatmullRomCurve3(路径点) → getSpacedPoints(N) 预采样
粒子状态 = {车道号, 浮点索引 t}；每帧 t += v·dt·(N−1)/L，越界回绕
渲染 = 单个 THREE.Points + canvas 径向渐变 sprite，additive 用于气体
流速 v = f(rpm, load)；冷却液还要乘节温器开度（水温<82℃ 时几乎不动）
```

一个介质一个 Points 对象（冷却液/机油/进气/废气 = 4 个 draw call）。

上面默认**闭环循环流**。家电/工艺设备常是**程序窗口控制的开环间歇流**（进水、
排水、喷射按程序时间 τ 的窗口开关）：车道不闭环，粒子越界时藏到起点等窗口再
放行即可；配**自由液面**时（洗衣机筒内积水），用液位驱动的弓形截面网格
（半宽 √(R²−y²)）每帧重建或缩放，别试图用粒子堆液面。
半透明流线 = 同一条曲线的 TubeGeometry，opacity .16，独立开关。
车道路径要**穿过真实几何内部**（顺着水套/油道/管路走），出错立刻穿帮。

## 4. 喷射/火花类瞬态

按主角度窗口开关的粒子锥/发光体：
`visible = (a >= 始角 && a <= 始角+持续)`，每帧随机抖动 opacity 模拟脉动。

## 5. 拆解动画引擎（96_teardown.js，~200 行，可整片移植）

数据结构：

```js
步骤 = { n:'中文名', en:'English', cam:{t,r,p,h},      // 每步镜头
         tip:'拆卸要点', spec:'装配规范/扭矩/间隙',      // 字幕卡两栏
         items:[ [网格数组, [dx,dy,dz], isKinematic?] ] }
```

核心机制——**加性偏移叠加在运动学之上**：

```js
进度 TD.t ∈ [0, N]（连续，可拖动）
每帧（在 updateKinematics 之后）：
  对每个登记网格：offset = Σ_steps easeInOut(clamp((t−stepIdx)·1.75)) · v
  静态件：position = 基准快照 + offset
  运动学件(isKinematic)：position += offset   // 运动学刚重写过，安全
```

这个设计让：进度条双向可拖、逆序装配 = t 递减、正在"运动"的零件也能被拆下、
退出后位置精确归零（有基准快照）。

进入/退出协议（必须完整，否则状态泄漏）：

- 进入：快照 {play, theta, clip, ghost, explode, flow}；暂停并把主角度转到
  该步骤序列需要的位形（发动机 = 目标缸下止点）；隐藏无关子系统与其余缸件
  （记录 hidden 数组）；构建位移表；镜头飞到第一步。
- 退出：t=0 应用一次归位 → 恢复 hidden → 恢复快照状态 → rebuildPick()。
- 换目标缸：先归零并 unhide，再切换重建。

步骤设计原则：按**真实检修顺序**（查该机器的维修手册顺序），每步 spec 写真实
扭矩/间隙/一次性件提示——这是教学价值的主要来源，不要写成空话。

移植提示：参考实现的拆解引擎带"目标缸"语义（多缸选择、按缸隐藏无关件）。
整机拆解类主题（家电/单转子机器）直接删掉目标选择层、把 tdVisible 简化成
"隐藏与拆解无关的系统"；跨父级的组（挂在浮动总成里的门/电机等）用 ANIM
引用喂给步骤表，不要依赖按 partId 查询的 BYPART（它查不到组）。

验收：进入→播放到底→逆序装回→退出，关键件坐标与初始快照逐位比对相等；
四个（全部）目标切换循环无残留隐藏、无报错。
