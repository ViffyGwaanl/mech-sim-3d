# 界面设计语言：去"AI 味"

真实用户对默认审美的原话是"太 AI 风了"。所谓 AI 味 = 黑底 + 霓虹青强调 +
玻璃拟态卡片 + 到处等宽字体 chip——这是生成式工具的默认套路，见多即廉价。
本篇是经用户验收的替代语言与令牌，新项目默认用它；只有用户明确要"科幻/
驾驶舱感"时才回到暗色系（旧令牌见 interaction.md 第 5 节，同样避免辉光滥用）。

## 默认语言：「产品摄影 × 工程手册」（paper 主题）

气质来源：工程图纸的图签与编号、维修手册的克制排版、产品摄影的白环幕布光。

令牌（CSS 变量原样抄）：
```
--paper:#f2efe7  页面底    --card:#fbfaf4  面板
--ink:#1c1e21    主文字    --ink2:#585d63  次级   --ink3:#8a8f95  弱化
--line:#d9d4c7   边框      --line2:#e7e3d8 内分隔
--acc:#d94f1e    唯一强调色（国际橙）
功能色：水 #33628f · 热 #c2410c · 低压制冷剂 #2563a8 · 高压 #b91c1c · 成功 #3a7d44
```

规则（每条都是气质来源，别打折）：

1. **强调色只有一个且吝啬地用**：活动态、实时数据、悬停描边、当前模式。
   橙色一多，纸面感立刻塌。
2. **禁**：backdrop-filter、发光阴影、渐变按钮、深色玻璃卡。面板=纸面卡
   （--card 底 + 1px --line + 4px 圆角 + `0 1px 2px rgba(30,28,20,.08)`）。
3. **图签 title block**：左上角用细线表格排「标题｜图号｜比例｜单位｜版次」，
   一个元素定调全局。图号编个像样的（WD-DRY-003 这类）。
4. **编号章节**：面板标题"01 烘干技术 DRY MODE"+ 底部细规则线（CSS counter）。
5. 数字一律 ui-monospace + tabular-nums；英文小标签 --ink3 + 字距，不再染色。
6. 图表 canvas：透明底融入纸卡、轴刻度 --ink2、网格 --line2、基准线墨色、
   当前对象橙色加粗、其余灰/蓝细线；图下配"图 1 ×××"式图注。
7. 三维标注 sprite：白底圆角小卡 + 1px 墨边 + 墨字 + 橙色序号圆点。
8. 控件：按钮白底墨框（激活=橙底白字）、滑杆 2px 细轨+橙色已走段+白底墨圈
   拇指、勾选=方形墨线、radio 卡当前行左侧 3px 橙竖条。

**三维场景必须配套重打光，只换 CSS 会穿帮**：背景与雾 #e9e6de；环境画布改
亮白摄影棚；Hemi 天白地 #cfcbc0；阴影透明度 ~.26；曝光降到 ~0.94；地面=
白环幕产品摄影台（哑光白圆台 + 边缘墨色发丝线 + 淡转盘刻度），删霓虹光环；
辉光只留真发热件且 strength ~.5；悬停描边 = 橙，讲解多零件高亮 = 蓝；
vignette 删除或极淡；亮背景下全部材质 envMapIntensity ×0.6 左右防金属过曝。

## 多配置机器的呈现铁律

用户切换机型/配置时，**一切呈现随之联动**——不只 3D 显隐：系统显隐面板只
列当前配置的模块行（行首徽章标机型）、三维标注按配置打 tag 联动、拆解表按
配置重建、任何 UI 路径都不得把异配置零件点出来。验收断言：每种配置下遍历
面板全部开关两次 + 爆炸拉满 + 拆解全程，深遍历场景零异配置网格可见。
（此坑真实发生过：3D 切对了、面板还能勾出错误机型混装。）

## 交叉检查

换主题=全局动作，逐项过：canvas 图表、sprite 标注、字幕卡、引导浮层、
加载页、上下文丢失提示、图例、HUD、粒子颜色（霓虹青粒子在纸面上最扎眼）、
högl 亮/描边色。留下任何一处旧主题残余都会被一眼看穿。
